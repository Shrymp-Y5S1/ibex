# ----------------------------------------------------------------------------
# 三、Verilog Include 搜索路径（在 Vivado 中设置）
# ----------------------------------------------------------------------------
# 设置方法: Tools → Settings → General → Verilog Options → Verilog Include Directories
# 或在 Sources 窗格中右键 Design Sources → Source Node Properties → Include Directories
#
# 需要添加以下路径（所有路径相对于项目根 E:\FPGA_FI_UI）：
#
#   1. ibex/rtl/                                           (ibex_pkg.sv等)
#   2. ibex/rtl/fi/                                        (FI模块)
#   3. ibex/shared/rtl/                                    (ram_2p.sv)
#   4. ibex/vendor/lowrisc_ip/ip/prim/rtl/                 (prim_assert.sv系列)
#   5. ibex/vendor/lowrisc_ip/ip/prim_generic/rtl/         (prim_ram_2p.sv系列)
#   6. ibex/vendor/lowrisc_ip/dv/sv/dv_utils/              (dv_fcov_macros.svh)
#   7. rtl/new/                                            (fault_count.v)

# ----------------------------------------------------------------------------
# 四、编译顺序建议
# ----------------------------------------------------------------------------
# Vivado默认自动推导编译顺序，但以下文件必须最先编译：
#
#   ☆ ibex_pkg.sv（定义全局 package ibex_pkg，被所有Ibex模块导入）
#
# 建议在Vivado中将 ibex_pkg.sv 设置为 Global Include 或使用以下属性：
#   右键文件 → Set Global Include
#
# 对于 fault_count.v：
#   右键文件 → Set File Type → Verilog（不是SystemVerilog）

# ----------------------------------------------------------------------------
# 六、Xilinx IP 清单（通过 IP Catalog 生成）
# ----------------------------------------------------------------------------
#
#   IP名称                  | Vivado IP 目录              | 用途
#   ----------------------- | --------------------------- | ------------------
#   Clocking Wizard         | clk_wiz_0                  | 时钟生成（MMCM/PLL）
#   SEM IP                  | sem_ultra_0_example_design | 故障注入控制器
#   (可选) VIO              | vio_0                      | 调试信号监视
#
#   clk_wiz_0 端口需求（参考C906设计）：
#     clk_in1_p / clk_in1_n : 差分输入时钟
#     clk_out1 : CPU核心时钟 (e.g. 50-100 MHz)
#     clk_out2 : (未使用)
#     clk_out3 : SEM IP时钟
#     clk_out4 : fault_count系统时钟 (e.g. 100 MHz)
#     clk_out5 : (未使用 / VIO)
#     resetn   : 外部复位
#     locked   : PLL锁定指示
